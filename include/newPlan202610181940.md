对你的最小可行算法栈：

解析 IK → 关节空间 S 曲线同步插补 → 底座多轴时间对齐
→ 位置回读慢积分校正 → 回程差/齿隙补偿 → 重力下垂补偿表
→ 状态机 + 超时/报警 → 示教回放

这套在 F103C8T6 上完全跑得动。

三、针对你的异构系统的推荐组合

算法选型

- 臂：几何解析 IK + 关节空间七段 S 曲线 + 位置回读校正 + 重力下垂补偿
- 底座：闭环驱动板位置模式 + 多轴时间对齐（两轴按距离比例缩放速度）；只有题目要求直线轨迹时才切速度模式 + DDA
- 协调：粗精分配（底座网格粗定位 + 臂中心区域精定位）+ 移动前收臂
- 冗余：不用零空间优化，用查表 + 规则即可

项目借鉴路线

1. SO-ARM100/LeRobot → 看总线舵机如何做多舵机同步读写、标定、示教回放
2. DevClaw → 裁剪它的 S 曲线、DLS IK、安全 FSM、标定模块（不要照搬动力学/CTC）
3. SmartArm / Abot → 看 F103 上如何做 1 kHz 实时插值和 CAN/步进协同
4. libscurve / grbl → S 曲线和 DDA 的嵌入式 C 实现
5. MoveIt / TOPP-RA → 只在上位机用，不要把整套搬到 F103

不建议照搬的

- MoveIt / OMPL / TOPP-RA / Pinocchio：F103 资源不够，放上位机
- CTC / RNEA / 阻抗控制：舵机没有力矩接口，除非用电流模式
- 完整 LeRobot 模仿学习栈：需要上位机/Jetson，F103 只做执行
- DevClaw 的 7 层全栈：对 F103 过重，选 2~3 个模块即可

四、给你的落地顺序

1. 第一版：解析 IK + 关节空间 S 曲线 + 底座位置模式时间对齐 + 状态机
2. 第二版：位置回读校正 + 回程差/齿隙补偿 + 单向趋近 + 重力补偿表
3. 第三版：粗精分配 + 示教回放 + 故障保护
4. 进阶：笛卡尔直线（上位机 TOPP-RA）、视觉伺服、模仿学习

一个提醒：搜索结果里部分国内仓库（尤其 DevClaw）功能描述很“全”，但实际完成度和代码质量需要你自己拉下来确认，不要只看 README。SO-ARM、Dummy Robot、grbl/Marlin 这几个是经过社区长期验证的，可信度最高。
