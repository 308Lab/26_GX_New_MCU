# 通信协议：视觉与 MCU v1.5.1

> 最后编辑时间 10-25 编辑者 ryanz
> 状态：当前版本（替代 v1.5；v1.5 与 v1.5.1 语义不兼容）

## 0. 帧格式

```
A5 CMD LEN DATA[0..LEN-1] XOR
```

`0xA5` 帧头；XOR 覆盖 `CMD/LEN/DATA`（不含 `0xA5`）；int16 大端；坐标单位 mm。

## 1. 通用约定

- **心跳**：`0xFE`（LEN=0）由**视觉→MCU 单向**发，5Hz；MCU 只收不回、不主动发；MCU 连续 500ms 收不到视觉任何帧 → 判失联，停追踪、回展开态。视觉不判 MCU 活。
- **ACK**：仅 MCU 回，`A5 FF 01 <CMD> <XOR>`；**豁免**（不回 ACK）：`0x23/0x26/0x33/0x43`、`0xFE`、`0xFF`、`0x14`。视觉不回 ACK。
- **相机**：两路常开。底盘相机做车底盘对准/顺序判定；腕部相机做机械臂追踪（B 因物料矮，粗调也用腕部）。
- **XY 追踪**：流式偏移只给平面 `dx/dy`（4B），**不含 z 深度**；z 由 MCU 按预设距离/接近策略处理。

## 2. 工具坐标系

- 原点：B/D = 夹爪 TCP，C = 激光出射点；
- 轴向：`x` 向左、`y` 向上、`z` 法向（指向目标），右手系（左 × 上 = 前）；
- 追踪偏移 `(dx,dy)` 是**相对当前工具基准点、工具系下的平面偏移**；
- MCU 换算：`目标基座坐标 = 当前位姿 + R_tool→base · (dx, dy, 0)`，`R` 由 FK 得（相机安装偏差并入），无 `tool_deg` 字段。

## 3. 典型任务流程

```
1 小车靠近目标区域
2 开始扫描 0x28/0x38/0x48（视觉复位、选检测器、选相机）
3 缓慢扫描（MCU 驱动底盘），请求中位线判定 0x20/0x30/0x40
4 中位判定成功 0x21/0x31/0x41（1=已进入中位线范围）
  → 车底盘与任务执行区的相对位置确定
5 请求开始判定顺序 0x29/0x39/0x49
6 小车前进，同时视觉计算目标顺序 → 回 0x2A/0x3A/0x4A（目标球升序名次 0/1/2）
7 小车按名次前往对应预设目标位置
8 再次请求中位线判定 0x20/0x30/0x40 → 0x21/0x31/0x41（重新定位底盘）
9 机械臂前往预设位置
10 开始追踪 0x22/0x32/0x42（Hz）→ 流式 0x23/0x33/0x43（dx,dy 修正，微调机械臂）
11 执行任务（B 放置段 0x25→0x26→0x27；C 激光等 0x35 或 3s 关；D 抓取）
12 停止追踪 0x24/0x34/0x44 → 小车离开，前往下一任务地点
```

要点：

- **中位线判定管车底盘**：底盘运动时，目标几何中心进入摄像头中位线判断范围即判定成功（意图 = 车底盘与目标对准）。同一任务中出现两次（第 4 步初对准、第 8 步重新定位），MCU 可重复请求。
- **顺序判定管目标选择**：第 5 步请求后视觉随车前进持续检测，把目标球在前进方向升序中排到第几位回给 MCU（0/1/2），MCU 据此去预设目标位置。
- **流式 xy 管机械臂微调**：第 10 步机械臂到预设位后，视觉只回目标在工具系下的平面修正量，闭环微调。
- 三种位置类信息：顺序名次（0x2A）、是否进入中位线（0x21）、xy 修正（0x23）——就这三样，不额外造。

## 5. 载荷

### 5.1 判定值

- `0x21/0x31/0x41` 中位线判定：`0` 未检出 / `1` **已进入中位线范围** / `2` 偏左未进入 / `3` 偏右未进入。判据：目标几何中心与画面竖直中线之差 `|d| ≤ 5% 画宽` 即进入范围；`2/3` 同时告诉 MCU 往哪边微调才进得去。用途 = 车底盘对准。
- `0x2A/0x3A/0x4A` 顺序名次：目标球在**基座系前进方向（x 轴）升序**中的名次，`0` = x 最小（离车最近）/ `1` = 中 / `2` = x 最大（最远）；单目标恒 `0`；未检出回 `1`。用途 = 选预设目标位置。

### 5.2 错误码（`0x12`）

| 码 | 含义 |
| --- | --- |
| `0x00` | 保留，勿用 |
| `0x01` | 码内容非法（非三位数） |
| `0x02` | 标定/手眼变换缺失或分辨率不匹配 |
| `0x03` | 检测器未就绪 |
| `0x04` | 目标未检出 |
| `0x05` | 追踪 60s 超时 |
| `0x06` | 深度无效 |

### 5.3 其余

- `0x11`：LEN=0；三位数仅视觉内部用于选检测器；
- `0x13`：LEN=0，追踪失稳时发一次；
- `0x14`：基座系 xyz（int16），视觉只记录不回；
- `0x22/0x25/0x32/0x42`：控制周期 Hz，int16，建议 50；
- `0x23/0x26/0x33/0x43`：`dx,dy` 各 int16 大端（4B），工具系平面偏移，**无 z**。

## 6. 超时与兜底

| 场景 | 规则 |
| --- | --- |
| 扫码 | 1s ×3 重发，失败则任务错误 |
| 顺序判定 | 视觉算稳即回 `0x2A`（建议 3s 内）；3s 无回包则 MCU 按 `1=中` 兜底，不停车 |
| 中位线判定 | 500ms 无回包则 MCU 重发（扫描阶段可反复请求，直到成功或任务超时）；失败不停车 |
| 追踪丢失 | 500ms 无偏移即判丢；视觉每失稳段发一次 `0x13` |
| 丢失兜底 | 连续 5 次 → 回展开态重粗调，**永不停机** |
| 追踪上限 | 60s 未收到停止 → 视觉发 `0x12(0x05)` 停流 |
| 激光 | `0x35` 或 3s 超时关断 |

## 7. 帧示例

```text
心跳:                A5 FE 00 FE
B 开始扫描:          A5 28 00 28
B 开始判定顺序:      A5 29 00 29
顺序名次 0:          A5 2A 01 00 2B      (1 → 2A, 2 → 29)
B 请求中位线:        A5 20 00 20
中位线 0/1/2/3:      A5 21 01 00 20 / 01 21 / 02 22 / 03 23
B 开始追踪 50Hz:     A5 22 02 00 32 12
流式 dx=10,dy=5:     A5 23 04 00 0A 00 05 28
B 停止追踪:          A5 24 00 24
扫码成功:            A5 11 00 11
错误 0x04:           A5 12 01 04 17
C 目标倒下:          A5 35 00 35
ACK 0x21:            A5 FF 01 21 DF
```
