## 关键不兼容点（v1.5 → v1.5.1）

| CMD | v1.5 | v1.5.1 |
|---|---|---|
| `0x21/0x31/0x41` | 6B 首物体绝对 xyz | 1B 中位线判定：0=未检出，1=进入，2=偏左，3=偏右 |
| `0x2A/0x3A/0x4A` | 0/1/2 = 左/中/右 | 0/1/2 = 最近/中/最远（x 升序名次） |
| `0x23/0x33/0x43` | 6B dx/dy/dz | 4B dx/dy，无 z |
| 心跳 | 双向 | 视觉→MCU 单向 5Hz |
| 追踪丢失 | 2 次后停车 | 5 次后回展开态重粗调，永不停机 |
